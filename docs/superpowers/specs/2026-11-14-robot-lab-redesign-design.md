# adnan070.me: Robot Lab на главной + новый README профиля

Дата: 2026-11-14 · Статус: черновик на одобрение

## Зачем

Adnan хочет сайт «как yousef-portfolio»: интерактивную 3D-лабораторию, где робот ездит между зонами, а каждый проект открывается разбором «How it works». Одновременно нужно привести README профиля GitHub (`Nanda070/nanda070`) к уровню референса `yousefJooX` и сделать главным проектом **Val Qauym** (valqauym.kz).

Аудитория и цель сайта не меняются (сейчас: backend-роли part-time, Венгрия / EU / remote).

## Цели

1. `/` — Robot Lab: полный форк `ref/robot-lab-portfolio-main/index.html` (Three.js r128 + GSAP + hairline), с контентом Adnan и его палитрой.
2. Val Qauym — главный проект: отдельная крупная зона в центре лаборатории, первый в списках, самый подробный разбор.
3. Классические страницы (`/work`, `/resume`, `/contact`, RU и HU версии) остаются как «быстрый путь» и получают редизайн в духе лаборатории.
4. Новый README профиля: баннер-терминал с точечным портретом из аватарки, таблица проектов, stats-карточки, змейка, единые контакты и роль.

## Не цели

- Остальные три стиля референса (OS, Spotlight, Desk Story) не переносим.
- Озвучка не нужна: ни mp3, ни голос браузера.
- Не переписываем Robot Lab на компоненты Astro и не меняем Three.js на что-то новее.
- Не меняем аудиторию, тексты резюме и список проектов по существу.

## Анти-цели (провал, даже если «работает»)

- Главная, которая не грузится или тормозит на слабом ноутбуке/телефоне без запасного пути к проектам.
- Чужие данные или стиль yousef на сайте: имя, янтарная палитра, его проекты, его CV.

## Как устроено

### Главная `/` = Robot Lab

- `src/pages/index.astro` отдаёт **собственную HTML-страницу** без `Layout.astro`: разметка, CSS и скрипт из референса почти дословно (`is:inline`).
- Данные не дублируются: на этапе сборки из `src/data/site.ts` собирается объект и вставляется в страницу как `window.LAB = {...}` (вместо `data.js`). Так проекты описаны в одном месте.
- `vendor/hairline-0.5.0.js` + лицензия → `public/lab/vendor/`. Three.js r128 и GSAP 3.12.5 — с cdnjs, как в оригинале.
- Палитра лаборатории = токены сайта: фон `#060913`, панели `#0c1222`, линии `#1f2a47`, текст `#e9eefc`, muted `#8793b3`, акцент `--accent` = signal `#7c9bff`, `--cool` = mint `#5bf5b0`, вторичный акцент flare `#ff6b9a`. Шрифты сайта: Unbounded (display), Hanken Grotesk, JetBrains Mono. Цвета 3D-материалов берутся из тех же CSS-переменных.
- Удаляется вся озвучка (кнопка Voice, клавиша M, `say()`/`speak()`, папка voice).
- Кнопки HUD: «All projects ☰» (список в модалке, как в оригинале), «Resume ↗» → `/resume`, переключатель языка EN · RU · HU (RU/HU ведут на `/ru`, `/hu`). Интро: «Start →», «Just show me the projects» (→ `/work`), «Resume».
- Запасные пути из оригинала сохраняются: без WebGL — сообщение и список проектов; `prefers-reduced-motion` уважается.
- Лаборатория только на английском. `/ru` и `/hu` остаются классическими главными (с ссылкой «3D Lab (EN)»).
- Текущая EN-главная переезжает на `/about`, чтобы не потерять контент; в навигации классических страниц появляется ссылка «Lab» → `/`.

### Разборы «How it works»

В `site.ts` у проекта появляется необязательный блок `lab`: `cat`, `tag`, `big` (главное число), `kpis`, `flow` (шаги), `notes` (решения), `bars` (необяз.). Полный разбор получают **Val Qauym, Juniper, Cheterin, VALORANT Quests**; остальные — карточку из текущих `summary`, `bullets`, `stack`, ссылок.

Val Qauym (источник — приватный репо `Nanda070/VALORANT` docs и публичный valqauym.kz; Adnan разрешил брать нужное):
- Роль: создатель, руководитель команды разработки; бот, сайт, панель и экономика (так указано в credits).
- Цифры: ~33 модуля бота, ~44 группы API панели, 3 поверхности (бот, панель, публичный сайт), ~945 участников сервера (живой счётчик на момент сборки — подпишем «на ноябрь 2026»), RU/EN.
- Пайплайн кастомки: лобби → вход соло/по коду → ранг → баланс команд → голосование карты → перенос в войсы → матч → автозакрытие по данным матча или ручной счёт → Elo, XP, сезонные токены → уборка ролей и войсов.
- Решения: бот и HTTP API в одном процессе; логика в `*_core`, которую используют и команды бота, и панель; Elo от шанса победы с поправкой на ACS/KDA; «честные» игры с хешем sha256 исхода до игры; игровые ивенты (Мафия, Бункер) в браузере по личной ссылке через WebSocket; турниры с очередью уведомлений.
- Стек: Python, discord.py, aiohttp, React + Vite + TypeScript, SQLite, nginx, systemd.
- Не публикуем: env-переменные, адреса, контакты других людей, внутренние названия файлов.

Juniper, Cheterin, Quests — цифры только те, что уже есть на сайте (1.29M серверов, 4.9M пользователей, p95 1.4 s → 18 ms, CPU 85% → 15% и т. п.).
